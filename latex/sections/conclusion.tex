\section{Conclusion}
\label{sec:conclusion}

This paper investigates whether an offline reinforcement learning agent equipped with
a CVaR reward function and macroeconomic state variables can produce equity portfolios
with superior risk-adjusted performance out-of-sample relative to classical benchmarks
on the Brazilian stock exchange B3.
We formulate the portfolio rebalancing problem as a Markov Decision Process, construct
a 225-dimensional state vector that encodes asset-level return dynamics together with
SELIC regime indicators, CDS spreads, and credit spreads, and train a
Conservative Q-Learning (CQL) agent on an offline dataset generated by the
Minimum-Variance Portfolio behavioral policy.
Under a strict walk-forward evaluation protocol with 35 quarterly folds spanning
2016--2024, the full proposed model (configuration A4) outperforms all three
classical benchmarks---Equal-Weight, MVP, and Risk Parity---in Sharpe ratio,
Sortino ratio, CVaR, and Calmar ratio, with the largest gains concentrated during
rising-rate regimes.

The contributions of this paper are threefold:

\begin{enumerate}
  \item \textbf{Regime-aware offline RL for emerging markets.}
        We demonstrate that combining CQL's conservatism guarantees with explicit
        macroeconomic regime signals produces a portfolio strategy that is both
        methodologically sound---free of look-ahead bias---and practically superior
        to classical benchmarks in the context of the Brazilian equity market.

  \item \textbf{CVaR reward shaping for tail-risk control.}
        The ablation study confirms that replacing the Sharpe-based reward with a
        CVaR-based objective improves out-of-sample risk-adjusted performance
        independently of the macro state information, providing evidence that
        tail-risk-aware reward design is a robust improvement over symmetric
        variance-based objectives in fat-tailed emerging-market return environments.

  \item \textbf{Empirical evidence on the value of macro conditioning.}
        The incremental gain from including SELIC regime, CDS, and credit-spread
        variables in the state vector---isolated in the A3-to-A4 comparison---
        provides empirical support for the hypothesis that monetary-policy context
        is a material input to equity portfolio allocation decisions in Brazil,
        consistent with the theoretical literature on regime-switching asset pricing.
\end{enumerate}

Several directions for future research present themselves.
First, extending the asset universe to include fixed-income instruments, currency
futures, and real-estate investment trusts (FIIs) would test whether the
regime-awareness of the framework generalizes across asset classes.
Second, incorporating realistic transaction costs and market-impact models would
provide a more accurate picture of the net-of-cost performance improvement
available to institutional investors.
Third, replacing the rule-based SELIC regime classifier with a real-time macro
nowcasting model or a hidden Markov Model could reduce the regime-labeling lag
and further improve performance during transition periods.
Finally, exploring alternative offline RL algorithms---such as Decision Transformer
\citep{Chen2021} or IQL \citep{Kostrikov2021}---within the same framework would
broaden the evidence base for offline RL as a tool for financial portfolio
optimization in emerging markets.
